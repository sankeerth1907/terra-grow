      Accuracy & limitations
        
      
      
This build classifies by per-pixel color rules — a fast, transparent stand-in for a trained
        segmentation model. Shadows, haze, seasonal crops and mixed pixels can shift classes by a few
        percentage points. Treat percentages as directional; for parcel-level decisions, connect a trained
        model (model.onnx / .h5 / .pt via app.py) or verify on the ground.
